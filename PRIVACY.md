# Aurora plugin privacy

This Aurora distribution contains local instructions, scripts, design assets, fonts and compiled UI components. It does not configure an MCP server, an Aurora analytics service, payment processing or a remote project upload service.

Project binding reads package files and writes the Aurora runtime and contract into the project you select. The preview helper starts a local HTTP server. No Aurora account is required for the packaged offline resources.

Your Codex host processes prompts and project context according to that host's settings and policies. GitHub receives ordinary repository/download requests when you install or update from this repository. Live Figma or GitHub operations, when requested, use your configured integrations and their own permissions and privacy policies.

Contact the distribution maintainer through the repository's issue tracker: https://github.com/curefitdesign-ux/aurora-design-system/issues
