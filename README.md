# Aurora Design System 2.0 — Organization distribution

Access is restricted to the organization. The repository is private and its earlier public Pages preview has been disabled. A private repository is an admin import source; workspace availability is managed separately.

The shared Codex plugin release is recorded in `latest.json`. Release 2.0.13 halves light-mode Aurora background intensity, uses pure-white cards with independent opacity, and keeps gradient CTA labels white. Existing installations and older workspace skill imports must be updated to adopt the new release; publishing the repository does not automatically replace an organization-managed skill. The component-only package excludes heavy source renders.

Repository source: https://github.com/curefitdesign-ux/aurora-design-system

Workspace admins can import a pinned repository ref under Admin > Plugins > Import marketplace, or upload the prepared skill under Workspace Settings > Skills and set workspace access. Importing a private source requires the admin's GitHub authorization; ordinary members use the workspace skill rather than receiving repository credentials.

Official workspace import guidance: https://learn.chatgpt.com/docs/enterprise/plugin-management
