# Aurora Design System 2.0 explorer

This is the generated handbook for the single Aurora Design System 2.0 skill.
It uses the same component explorer as `packages/aurora-library/demo/`.

Run `python3 scripts/serve-aurora-preview.py` from the repository root and open `/dashboard/`. The runtime lives under
`skills/aurora-design-system/assets/runtime/react/`; do not serve only this folder.
The installed plugin's preview helper serves its package root automatically.

The explorer includes category navigation, searchable aliases, live controls,
source states, fitted previews, code snippets, foundations and coverage.
Use `node packages/aurora-library/build/demo.mjs` after building the library
and refreshing the coverage ledger to regenerate it.

The previous handbook is preserved at `archive/handbook-before-2.0/`.
